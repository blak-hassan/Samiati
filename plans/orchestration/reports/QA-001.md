**Confirmed findings and independent fix candidates**

1. **P2 — Submitted corrections lose the community-review action.**
   After a successful correction submission, [FeedbackBar.tsx:159](C:/Users/pc/Documents/samiati-1.0/src/components/feedback/FeedbackBar.tsx:159) clears `correction`, but [line 322](C:/Users/pc/Documents/samiati-1.0/src/components/feedback/FeedbackBar.tsx:322) requires that value to display the promotion action and reference. Expected: the saved correction remains available for promotion. Actual: that branch becomes unreachable.
   **Owner:** Changa & Feedback. **Allowed file:** `src/components/feedback/FeedbackBar.tsx`. **Smallest fix:** retain submitted correction text separately from the editable input. **Dependency:** existing feedback response contract; no backend change required.

2. **P2 — Review advancement skips remaining submissions.**
   [ValidationRunner.tsx:63](C:/Users/pc/Documents/samiati-1.0/src/components/changa/ValidationRunner.tsx:63) selects by numeric index; [line 85](C:/Users/pc/Documents/samiati-1.0/src/components/changa/ValidationRunner.tsx:85) increments it after voting. Meanwhile, [validation.ts:106](C:/Users/pc/Documents/samiati-1.0/convex/changa/validation.ts:106) removes items already reviewed by that user. With queue `[A,B,C]`, voting on A leaves `[B,C]` at index 1, selecting C and skipping B. A shorter queue can leave no current item despite remaining work.
   **Owner:** Changa & Feedback. **Allowed file:** `src/components/changa/ValidationRunner.tsx`. **Smallest fix:** use stable item identity and reconcile selection after queue updates. **Dependency:** preserve the existing reactive query contract.

3. **P2 — Recent sessions hides every pinned conversation.**
   On `/dashboard/saved-conversations`, select **Recent** with a pinned conversation present. [SavedConversationsScreen.tsx:143](C:/Users/pc/Documents/samiati-1.0/src/components/screens/SavedConversationsScreen.tsx:143) suppresses the pinned section, while [line 65](C:/Users/pc/Documents/samiati-1.0/src/components/screens/SavedConversationsScreen.tsx:65) excludes pinned items from the other section. Expected: all matching sessions sorted by activity. Actual: pinned sessions disappear; an entirely pinned history produces a blank list without an empty state.
   **Owner:** Chat & Languages. **Allowed file:** `src/components/screens/SavedConversationsScreen.tsx`. **Smallest fix:** render the complete sorted list for Recent. **Dependency:** existing local-history format only.

4. **P2 — Guest Discover-to-chat handoff discards the question.**
   Discover sends `?q=` at [DiscoverScreen.tsx:81](C:/Users/pc/Documents/samiati-1.0/src/components/screens/DiscoverScreen.tsx:81), but the guest branch at [dashboard/page.tsx:102](C:/Users/pc/Documents/samiati-1.0/src/app/dashboard/page.tsx:102) omits `initialQuery`. The receiving [HomeSearchScreen.tsx:425](C:/Users/pc/Documents/samiati-1.0/src/components/screens/HomeSearchScreen.tsx:425) also ignores it without a user. Expected: the selected question remains visible as a draft through the sign-in handoff. Actual: guests reach a blank composer.
   **Owner:** Chat & Languages; Discover supplies the contract. **Allowed files:** `src/app/dashboard/page.tsx`, `src/components/screens/HomeSearchScreen.tsx`. **Smallest fix:** preserve and display the guest query without sending it. **Dependency:** retain the existing `?q=` contract.

5. **P2 — An unsupported checkout plan crashes rendering.**
   Open `/checkout?plan=organization` or `/checkout?plan=invalid`. [checkout/page.tsx:21](C:/Users/pc/Documents/samiati-1.0/src/app/checkout/page.tsx:21) initializes state from an unchecked cast. Consequently, `planDetails[plan]` is undefined and [line 36](C:/Users/pc/Documents/samiati-1.0/src/app/checkout/page.tsx:36) dereferences it. The effect’s validation occurs too late. Expected: a supported fallback or an explicit invalid-plan state.
   **Owner:** Account & Settings / billing. **Allowed file:** `src/app/checkout/page.tsx`. **Smallest fix:** validate the parameter before initializing state. **Dependency:** existing supported plan identifiers; no payment changes.
