## 2. Gaps (the work remaining)

### A. Stale `src/app/favicon.ico` (real bug)
`src/app/favicon.ico` (16x16) still exists alongside `public/favicon.ico` (48/32/16). Next serves both as routes -> ambiguous favicon. Delete `src/app/favicon.ico`. Plan item 2.4 flagged this; it was never done.

### B. `--color-text-muted` contrast still fails
`globals.css:37` dark `--color-text-muted: #A8A29E` on `#2b1e19` = ~3.4:1, fails WCAG AA. Plan item 7.2 flagged this; never fixed. Also light theme `--muted-foreground: #6B6560` on `#FAF9F6` = ~4.4:1 (borderline). Fix both.

### C. ~30 raw `<img>` tags bypass `next/image`
Plan item 5.1 said migrate all `<img>` to `next/image`. `StorageImage` was migrated but screens still use raw `<img>` for avatars and post images (see grep results: PostCard, ContributionCard, CommentItem, SettingsShell, ValidationCard, ProverbDetailScreen, etc.). These bypass Next's optimizer. Either migrate or accept and document.

### D. No e2e for not-found / links
`e2e/not-found.spec.ts` and `e2e/links.spec.ts` do not exist. `e2e/mobile-first.spec.ts` exists. Plan items 9.3, 10.4 not done.

### E. No unit tests for consent gate or forms
`tests/cookie-consent.test.ts` and `tests/forms/contribution.test.ts` do not exist. Plan items 13.1, 11.4 not done.

### F. `check-mobile-first.mjs` and `check-image-sizes.mjs` missing
Plan items 8.1, 5.3 not done.

### G. `scripts/generate-og.mjs` missing
Favicons are generated by `scripts/generate-favicons.mjs` (which also writes og-image.png), so a separate `generate-og.mjs` is redundant. Remove from plan; keep the combined script.

### H. CI does not run the audit scripts
`ci.yml` runs lint/format/typecheck/test/build/gitleaks/bundle-budget/LHCI. The `check-*.mjs` scripts are not wired in. Add them as a CI job.

### I. Sitemap is static-only
`sitemap.ts` lists only STATIC_ROUTES. Dynamic Convex content (posts, challenges, contributions) is rendered via `searchParams`, not URL segments, so there are no per-record URLs -- this is a deliberate design decision, documented in `docs/seo-and-performance.md`. Accept; do not change.
